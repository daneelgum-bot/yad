

Пример кода matlab
дополнен - построение спектра полезного сигнала, отклик согласованного фильтра

ЗАДАНИЕ
Создать программное обеспечение, осуществляющее генерацию аддитивной смеси 
полезного сигнала, представляющего собой пачку радиоимпульсов, и помехи с нормальным 
законом распределения. Программа должна иметь удобный интерфейс и обеспечивать: 

➢ Ввод необходимых параметров; 
➢ Формирование массивов отсчетов сигнала, помехи и их аддитивной смеси; 
➢ Построение по выбору пользователя графиков сигнала и/или помехи и/или их 
аддитивной смеси. 
Параметры: 
• Число импульсов в пачке; 
• Длительность импульса (в секундах); 
• Частота повторений импульсов (в Гц); 
• Форма огибающей одиночного импульса (выбирается из двух вариантов: 
прямоугольная, половина периода синусоиды); 
• Амплитуда огибающей одиночного импульса (в вольтах); 
• Частота заполнения импульса (в герцах); 
• Начальная фаза импульсов (в градусах); 
• Частота дискретизации (в Гц); 
• Дисперсия шума (среднее значение шума считать нулю); 
Ограничений на способ вывода графиков нет. Однако, результат графического отображения 
должен быть наглядным, и все графики должны быть снабжены подписями по осям и 
заголовками.
